# Badge

Design a premium achievement badge titled "[BADGE_TITLE]".

Style direction:

- Inspired by modern SaaS gamification systems, Discord quest badges, GitHub achievements, and Duolingo rewards.
- Clean vector illustration.
- Minimal geometric composition.
- Flat 2D design with subtle depth.
- Smooth gradients.
- Soft shadows.
- Highly recognizable silhouette.
- Professional and collectible.
- Consistent visual language across an entire badge ecosystem.
- No realistic rendering.
- No 3D metallic medals.
- No fantasy RPG aesthetics.
- No clutter.

Visual identity:

- Large central icon representing the meaning of [BADGE_TITLE].
- Icon should be simplified into bold geometric shapes.
- Circular dark core element in the center.
- Dynamic star/compass-like background shape extending behind the icon.
- Elegant gradient accents.
- Small decorative sparkles and curved accent shapes.
- Symmetrical composition.
- Strong visual hierarchy.
- Friendly but professional.

Color palette:

- Deep navy (#0B1020)
- Vibrant Kotlin purple gradients
- Soft neon mint accents
- White highlights
- High contrast

Layout:

- Centered composition.
- Single badge only.
- Isolated on clean light background.
- Generous negative space.
- Vector quality.
- App-ready.
- SVG-style illustration.

Requirements:

- The badge must visually communicate [BADGE_TITLE] without using text.
- Replace the central symbol according to the achievement theme.
- Keep the exact same art direction, proportions, simplicity, and collectible feel.
- Maintain consistency with other badges in the same achievement system.

Output:
Modern flat vector achievement badge, premium quality, clean geometric shapes, smooth gradients, professional SaaS
gamification style, dribbble-quality design, centered composition, no text.
